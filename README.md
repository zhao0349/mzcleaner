## Q9：为什么有些文件没有被清理？

**A：**

可能存在以下原因：

* 文件正在被占用
* 文件属于系统保护目录
* 当前权限不足
* 软件为了安全默认跳过了部分目录

为了降低误删风险，本项目遵循"宁可少删，也不误删"的原则。
